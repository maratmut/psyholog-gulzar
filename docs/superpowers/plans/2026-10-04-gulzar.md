# Gulzar Redesign Implementation Plan

> **For agentic workers:** Execute inline with executing-plans; user approved implementation in this session.

**Goal:** Build the approved responsive standalone redesign, preserving real content and external purchase/booking destinations.

**Architecture:** Static HTML with shared CSS tokens, native details elements for long programs, and small vanilla JavaScript for navigation and a review lightbox. Local assets and a dependency-free Node preview server.

**Tech Stack:** HTML, CSS, browser JavaScript, Node.js; Python for public source extraction and asset preparation.

**Spec:** docs/design.md

## Global Constraints
- Gold accents instead of red; actual original photos and testimonials only.
- Preserve published content, prices, product conditions and original destinations.
- Responsive 360–1440px; keyboard and reduced-motion support.
- Local-only implementation; do not publish or change Tilda.
