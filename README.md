# Сайт психолога Гюльзар — React + Vite

Адаптивный сайт на React 19 и Vite. Сохранены согласованные дизайн, тексты, изображения, шрифты, ссылки оплаты и записи. Мобильное меню и просмотр изображений используют состояние React; раскрывающиеся разделы сохраняют нативное поведение.

## Запуск

Нужен Node.js 22.12 или новее.

```powershell
npm.cmd install
npm.cmd run dev
```

Откройте http://localhost:4173. На macOS/Linux используйте `npm` вместо `npm.cmd`. Сервер доступен только на локальном компьютере. Порт и адрес задаются в `vite.config.js`.

## Сборка и публикация

```powershell
npm.cmd run build
npm.cmd run preview
```

Готовый сайт находится в `dist/`. Для предпросмотра сборки сначала остановите dev-сервер: оба используют порт 4173. При необходимости другой порт: `npm.cmd run preview -- --port 4174`.

На Netlify или другом статическом хостинге:

- команда сборки: `npm run build`;
- каталог публикации: `dist`;
- установка зависимостей из lock-файла: `npm ci`.

Для Vercel настройки закреплены в `vercel.json`: Framework Preset `Vite`, команда сборки `npm run build`, каталог `dist`. Root Directory проекта должен быть корнем репозитория (поле пустое или `.`). После изменения конфигурации запускайте деплой актуального коммита `main`.

Публикуйте только `dist/`: вспомогательные `reference/`, `scripts/`, `tests/` и `docs/` в сборку не входят. Исходный сайт Тильды не изменён. HTML теперь является входной точкой React, поэтому открывайте сайт через dev-сервер или собранный сайт на хостинге.

## Структура

- `src/main.jsx` — запуск React.
- `src/App.jsx` — сборка страницы и состояние галерей.
- `src/components/` — шапка, первый экран, разделы, отдельные программы, подвал и просмотр изображений. Тексты редактируются в JSX соответствующего раздела.
- `src/styles.css` — исходный CSS без визуальных изменений; палитра в `:root`.
- `src/hooks/useSectionAnchors.js` — переходы по сохранённым ссылкам Тильды.
- `public/assets/` — фотографии, отзывы, локальные шрифты и лицензии.
- `index.html` — метаданные и контейнер приложения.
- `reference/` — снимок публичного оригинала и происхождение материалов.
- `scripts/` — вспомогательные инструменты подготовки материалов и проверки переноса. `render-content.py` относится к первоначальной статической версии и повторного запуска не требует.
- `tests/fixtures/original-site.json` — структура, тексты и контрольные суммы утверждённой версии до переноса; это эталон проверки, не источник отображаемого контента.
- `docs/` — дизайн и результаты проверки.

## Проверка

```powershell
npm.cmd run check
```

Команда сравнивает структуру и текст React-страницы с утверждённой версией, проверяет неизменность CSS и всех локальных материалов, затем собирает сайт. Отдельно: `npm.cmd test` и `npm.cmd run build`.

После `npm.cmd test` можно запустить `python scripts/check-site.py`: он проверяет 153 исходных текстовых фрагмента, адреса покупок, сообщение записи, якоря и файлы изображений. Python 3, без дополнительных пакетов.

Итоги проверки в браузере — `docs/verification.md`. Происхождение изображений — `docs/assets.md`.
