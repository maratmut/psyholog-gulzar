# Сайт психолога Гюльзар

Самостоятельный адаптивный сайт по согласованному референсу: светлый фон, выразительная типографика, золотистые акценты, настоящие фотографии и отзывы.

## Запуск

Нужен Node.js. Установка npm-пакетов не требуется.

```powershell
npm.cmd run dev
```

Откройте http://localhost:4173. `PORT` позволяет выбрать другой порт. Сервер слушает только локальный компьютер.

## Файлы

- `index.html` — готовая страница со всеми текстами; тексты можно редактировать прямо здесь.
- `styles.css` — цвета, типографика, адаптивная вёрстка; палитра находится в `:root`.
- `app.js` — мобильное меню, увеличение изображений, просмотр отзывов и совместимость старых якорей.
- `assets/` — локальные изображения, шрифты и лицензии шрифтов.
- `reference/` — снимок публичного оригинала, карта исходных текстов, фотографии до оптимизации и происхождение материалов. Не предназначен для публикации.
- `scripts/` — вспомогательные инструменты захвата публичного оригинала и проверки переноса. `render-content.py` был выполнен один раз: итоговый HTML уже содержит тексты и повторного запуска не требует.
- `docs/` — согласованный дизайн, план и результаты проверки.

## Размещение

Для статического хостинга достаточно `index.html`, `styles.css`, `app.js`, `favicon.svg` и `assets/`. Можно открыть `index.html` напрямую, но локальный сервер рекомендуется для полного предпросмотра. Сайт не опубликован и исходный проект Тильды не изменён.

Адреса юридических документов и расширенных отзывов должны оставаться доступными на прежнем домене. При полной смене хостинга домена эти страницы нужно перенести отдельно; в текущем локальном результате они открываются на исходном сайте. Аналитика Тильды не переносилась: при публикации следует подключить нужный счётчик с разрешёнными настройками. Перед публикацией добавьте абсолютные `og:url`, `og:image` и canonical с фактическим доменом.

## Проверка

```powershell
npm.cmd run check
```

Дополнительный `scripts/check-site.py` проверяет исходный текст, адреса покупок, сообщение записи, якоря и локальные файлы (Python 3, без зависимостей). Итоги проверки в браузере — `docs/verification.md`.

Происхождение изображений и подготовка портрета — `docs/assets.md`.
